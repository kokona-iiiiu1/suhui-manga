# 《溯洄》漫画作品展示网站 — 开发计划

> **For Hermes:** 按本计划逐步实施（见执行交接）。本计划只做规划，不含执行代码。

**Goal:** 为原创漫画《溯洄》制作一个开放访问的个人作品展示网站：任何人无需登录即可浏览全部 64 页漫画、人物设定与创作背景，并可匿名发表评论。

**Architecture:** 纯静态站点（HTML/CSS/JS，零构建依赖），素材统一从 TIFF 预处理为 WebP/JPG 后随站分发，评论用免费第三方服务（Waline 或 Giscus 类），整站部署到 GitHub Pages 免费托管，实现"打开网址即可访问、无需登录即可评论"。

**Tech Stack:** HTML5 + CSS3 + 原生 JS（无框架）、Pillow（TIFF→WebP 批量转换）、Open Design CLI（设计方向 tokens 生成）、GitHub Pages（托管）、Waline（匿名评论，可选）。

## 设计方向（来自 Open Design）

采用 `editorial-monocle`（Editorial/Monocle 杂志画册风）为主基调，适配"悲剧美学×海洋奇幻"：

- **字体：** 显示用衬线 `'Iowan Old Style', 'Charter', Georgia, serif`；正文同衬线族
- **基调：** 大留白、大号衬线标题、克制的印刷感、hairline 边框、无厚重阴影
- **配色（深蓝海洋系，将默认 oklch 映射为 hex 供浏览器兼容）：**
  - `bg` 深蓝黑 `#0b1220`（暗色首屏）＋ 米白 `#f7f5f0`（正文区）
  - `fg` 墨蓝黑 `#1a2332` / 浅区 `#0e1626`
  - `muted` 雾蓝灰 `#64748b`
  - `border` 浅海蓝 `#dbe4f0` / 暗区 `#24344d`
  - `accent` 贝壳珍珠青 `#4fd1c5`（点缀：章节标记、链接 hover）
  - 首屏 Hero 用深蓝渐变（深海→月光海面），正文区回到杂志米白
- **意象：** 贝壳、浪线分隔符、月相、衬线首字下沉（故事引言段落）

## 站点结构

```
manga-portfolio/
├── index.html            # 单页站（锚点导航，天然适合评论回流）
├── css/
│   ├── tokens.css        # :root 设计变量（Open Design tokens 落地）
│   └── main.css          # 布局与组件
├── js/
│   ├── reader.js         # 漫画阅读器（翻页/缩放/章节跳转）
│   └── main.js           # 导航、滚动动效、评论加载
├── assets/
│   └── img/
│       ├── pages/        # webp 页（00封面…57）
│       └── characters/   # webp 人物设定图
└── scripts/
    └── convert.py        # TIFF→WebP 批量转换（幂等，可重跑）
```

**页面布局（用户确认：左中右三栏）：**
1. **左侧栏（简介区）** — 固定宽约 280px：作品名、故事梗概（首字下沉引言）、世界观卡片（时溯贝/人鱼族/渔村）、人物设定摘要、创作团队
2. **中间栏（主展示区，弹性宽度）** — 漫画阅读器：**页漫翻页模式**（一次只显示一页，非条漫滚动）；章节分组（封面/相识/熟知/灾厄·轮回/封底）、←→ 键盘翻页、点击左右区域翻页、缩略图导航、页面预加载、全宽阅读模式
3. **右侧栏（评论区，固定宽约 300px）** — **预留占位**：先显示"评论区即将上线"占位块，不部署评论服务端；后续若需匿名评论再接入 Waline/Cusdis（均免费档）

## 分步实施计划

### Task 1: 素材转换与落盘（scripts/convert.py）
**目标：** 把 64 张 TIFF 转成 WebP 存入 `assets/img/`，保持文件名序号。

- 步骤 1: 写 `scripts/convert.py` — 遍历源目录，Pillow 打开 TIFF，转 RGB，存 WebP（quality≈82，`lossless=False`），输出到 `assets/img/pages/` 与 `assets/img/characters/`；已存在的同名文件跳过（幂等）
- 步骤 2: 运行并核对输出数量 = 58 页 + 5 人物图 = 63 张（封面封底含在内）；抽查尺寸
- 预期：单张 WebP 约 150~600KB，整站素材总量 < 25MB（GitHub Pages 友好）
- 验证：`python scripts/convert.py` 输出汇总行；`ls assets/img/pages | wc -l` = 58

### Task 2: 设计令牌落地（css/tokens.css）
**目标：** 把 Open Design editorial-monocle 的 tokens 写成 CSS 变量并调整为深蓝海洋系。

- 步骤 1: 运行 `od tools directions --id editorial-monocle --json` 取原始 tokens（已在会话中验证可用）
- 步骤 2: 手写 `css/tokens.css` — `:root{}` 定义上节色板/字体栈/间距节奏/动效时长，并写 `data-theme="dark"` 深蓝 Hero 段变量
- 验证: 打开 index.html 骨架时 CSS 变量生效（背景、字体可见）

### Task 3: 页面骨架（index.html + css/main.css + js/main.js）
**目标：** 单页结构 + 六个区块的静态骨架与基础样式。

- 步骤 1: 写 `index.html` 骨架：`<header>` 固定导航（锚点）、六个 `<section>`、`<footer>`
- 步骤 2: 写 `css/main.css`：杂志排版（大标题、留白、hairline 分隔、首字下沉）、导航样式、响应式断点（≥1024 / 768 / 480）
- 步骤 3: 写 `js/main.js`：平滑滚动、滚动高亮当前锚点、`.reveal` 入场动画（IntersectionObserver）
- 验证: 本地 `python -m http.server 8000` 打开，锚点跳转/动效正常

### Task 4: 漫画阅读器（js/reader.js + 阅读区块）
**目标：** 支持分组章节与键盘翻页的阅读体验。

- 步骤 1: 阅读器状态机：`currentIndex`（0~57）、`chapterMap`（封面0/相识1-?/熟知?/灾厄·轮回?/封底57，具体页号以 PPT 章节为准，实施时从报告/PPT 核实）
- 步骤 2: 渲染逻辑：主图 `<img loading="lazy">` + 底部缩略图条（左右滚动）+ 页码显示
- 步骤 3: 交互：←/→ 翻页、缩略图点击跳转、全宽模式切换（暗底）、触屏滑动
- 步骤 4: 预加载：翻页时用 `new Image()` 预取 ±2 页
- 验证: 连续翻页 58 页无错位，缩略图与主图同步

### Task 5: 人物设定区块
**目标：** 三张人物卡展示设定图与文字。

- 步骤 1: 从 `report.doc`（已提取文本）摘录克洛琳/莉芮尔/西娅文字设定，写成 HTML
- 步骤 2: 卡片布局：左侧三视图（或表情图）大图，右侧姓名/身份/性格/关键意象；hover 微交互
- 验证: 三卡齐全，图片加载正常，长文本无溢出

### Task 6: 评论区（预留占位，不部署）
**目标：** 右侧栏显示评论占位区，实现零依赖。

- 步骤 1: 右侧栏放"评论区"标题 + 占位说明（"评论区即将上线"），预留 `<div id="comments">` 挂载点
- 步骤 2: 预留 Waline 前端脚本注释块（`<!-- 接入 Waline 时取消注释 -->`），不实际加载任何第三方资源
- 验证: 页面右侧栏显示占位，无第三方请求（DevTools Network 无外部域）

### Task 7: 本地验收（QA）
**目标：** 全站功能验收。

- 检查清单：6 区块渲染、63 张图全部可加载、阅读器翻页/键盘/触屏、人物卡、评论发表、移动端视口（480px）、暗色首屏与米白正文的对比度
- 修复发现的问题

### Task 8: 部署上线（GitHub Pages）
**目标：** 开放公网访问。

- 步骤 1: 安装 gh CLI（本机无）：`winget install GitHub.cli` + `gh auth login`（需用户 GitHub 账号授权）
- 步骤 2: `gh repo create suhui-manga --public --source . --push`（仓库名可调整）
- 步骤 3: Settings → Pages → 部署 main 分支（或 Actions 流程）；等待 CNAME 生效
- 步骤 4: 访问 `https://<user>.github.io/suhui-manga/` 验收：图片、评论、移动端
- 验证: 手机浏览器打开公网地址，评论可匿名发表

4. **素材版权** — 公开部署前建议与组员确认作品对外展示授权（课程作业对外公开属敏感项，需用户确认）

6. **GitHub Pages 国内访问** — 偶发不稳定，若用户在国内需要更稳托管可后续评估 Vercel/Netlify 静态托管
